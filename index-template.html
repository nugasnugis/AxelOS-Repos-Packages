Secure static package mirror powered by reprepro & GitHub Pages

How to add this repository:

Run these commands to add the secure signature keyring and update your sources list:

# 1. Download the public repo security key
curl -sS https://${{ github.repository_owner }}.github.io/${{ github.event.repository.name }}/pubkey.gpg | sudo gpg --dearmor -o /usr/share/keyrings/myrepo-keyring.gpg

# 2. Add the source listing (Adjust "zena/suki" and "main/testing" variables below to fit your system setup)
echo "deb [signed-by=/usr/share/keyrings/myrepo-keyring.gpg] https://${{ github.repository_owner }}.github.io/${{ github.event.repository.name }}/ zena main" | sudo tee /etc/apt/sources.list.d/myrepo.list

# 3. Synchronize package updates
sudo apt update
